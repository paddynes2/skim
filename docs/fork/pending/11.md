## DECISIONS

- **2026-09-23 D-11a:** a guest's threads are `from:` OR `to:` the address. `Filters`
  ANDs its terms, so `thread_query` builds two `Filters` (each with `after:` and the
  default Trash/Spam exclusion) through `filter_sql` and ORs the two clauses; the
  grouping query is `search_threads`'s, plus `folderId` and `hitMessageId` on each row
  so the panel can call `mail.openLocation`.
- **2026-09-23 D-11b:** "external guest" = every attendee minus own addresses
  (`court::own_addresses`, case-insensitive), the entry Google marks `self`, and
  `resource: true` rooms; duplicates collapse, first display name wins.
- **2026-09-23 D-11c:** the reminder window is `[now, now+10 min]`, timed events only,
  `status != cancelled`, `self_response != declined`, on selected calendars
  (`events_between`). The UI polls every 60 s while open, toasts each event id once
  per session (60 s toast, "Prep" action), one toast at a time.
- **2026-09-23 D-11d:** the CRM card comes from the panel's own `fork_crm_lookup` call
  until `crm.rs` exposes a non-command lookup (seam 1 above); `PrepGuest.crm` is
  already in the payload so the switch is server-side only.
- **2026-09-23 D-11e:** `fork_prep_brief` reproduces `spawn_stream`'s Channel protocol
  rather than calling the private function (seam 2 above); brief capped at 1024
  output tokens, ~150 words by prompt, no citations.
