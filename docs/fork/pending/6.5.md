## DECISIONS

- **2026-09-23 D-6.5a (rules as data, not a port):** the TS scanner compiles the vendored
  JSON; nothing is re-typed. `compile()` throws on the first pattern V8 rejects and
  `smell.test.mjs` asserts that, so a bad export fails the build. Parity over 30 samples
  (2 clean exemplars, 21 warn fixtures, 6 hard fixtures, 1 mixed draft) is green; the
  test skips visibly when no OS checkout exists (a CI box).
- **2026-09-23 D-6.5b (offset-preserving mask):** OS strips fences / inline code / `>`
  lines to one space; the TS side blanks them to spaces of the same length so spans keep
  their offsets. A pattern spanning a stripped region could differ; none of the 120 do
  on the corpus.
- **2026-09-23 D-6.5c (the dash rule):** em / en dash is `hard` on every occurrence
  (`dash#0`), TS-only: OS owns it in `broker_draft_commit.voice_check`, not slop_scrub.
  Parity excludes `dash` and `contrast_repeat` by name.
- **2026-09-23 D-6.5d (document layer):** a contrast frame repeated >= 3 (no-smell's
  email `contrast_repeat` warn threshold, read from the export) underlines every
  occurrence at warn; the health line names the top frame from 2. `no clear position`
  only at >= 250 words (no-smell's `MIN_WORDS_FOR_LOW_RULES`) and < 3 positions / 1k.
- **2026-09-23 D-6.5e (`--smell-warn` token):** the theme has no amber; the injected
  sheet defines `--smell-warn` per theme (#b7791f light, #e0b45a dark). Should move to
  `tokens.css` (upstream file, not this agent's) as a fork state colour; violet stays on
  ✦ Rewrite only.
- **2026-09-23 D-6.5f (fact guard, two locks, no regex):** `fork::smell::guard` and
  `factguard.ts` are the same token walk (digits, URLs, emails, capitalised non-first
  words) so they cannot drift on a regex dialect. Rust filters what the model returned;
  the popover re-checks before offering. Both are tested on "R140,000" and "Tuesday
  14:00" changing.
- **2026-09-23 D-6.5g (rewrite returns, does not stream text):** `fork_smell_rewrite`
  returns `{options, rejected}`; the Channel carries `reasoning` / `delta` / `done` for
  liveness only. Not registered for `ai_cancel` (one short call). "Clean whole draft"
  is NOT built: the popover's per-sentence path is the unit; a whole-draft pass is the
  same call in a loop over flagged sentences with a before/after list, left for when the
  composer splice exists.
- **2026-09-23 D-6.5h (Node resolves `./scan`):** the app imports siblings without
  `.ts` (svelte-check forbids the extension); Node wants it. `src/fork/tests/
  ts-resolve.mjs` is a `module.register` hook the test and the parity script install
  themselves, so the documented commands stay `node --test ...` / `node scripts/...`.
- **2026-09-23 D-6.5i (settings key):** `fork_smell_ignored` (as pre-listed), not
  `fork_smell_ignored_rules`.
